# 前端设计约定（实战沉淀）

## 1. 主题 = 令牌，不是重写

- 所有颜色必须进 `:root` 语义令牌（`--text3`、`--danger-soft`……），组件只写 `var(--*)`。
- 换肤 = 换令牌值，不改令牌名、不动结构规则（grid/尺寸/overflow）。本仓库契约测试锁定了大量 CSS 结构字符串，这是唯一零风险换肤路径。
- 硬编码色值是债：终端化改造时清了 135 处硬编码浅色。新代码出现裸 hex 视为审查不通过。

## 2. 颜色承载信息，不是装饰

配色语义即日志级别/diff 语义：收益 `+绿（--accent-h）`、损失 `-红（--danger-h）`、警示琥珀（--warn-h）、信息蓝（--primary）。新状态先问"它属于哪个语义"，再取对应令牌，不发明新颜色。

## 3. 签名件原则（风格预算只花在 1-2 处）

- 把风格重量押在少数"签名交互"上（本项目：commit log 人生日志、Ctrl+K 人生终端），周边保持安静克制。
- 明确放弃过的廉价氛围件：扫描线、CRT 闪烁、全局 glow——显 AI 味且伤可读性。想加特效先对照此条。
- 反差点缀有价值：全冷色终端里保留贴纸式浅底头像（--avatar-bg），一处暖色即可。

## 4. 说目标用户的母语

界面隐喻取自程序员日常工具：git（日志/revert）、终端（命令面板/提示符）、oncall（P0 告警条 + "值班人：你自己"）。英文命令词只做风味符号；**所有正文、提示、错误必须中文产品化**——禁止英文异常、堆栈、状态码进用户视野（AGENTS.md 硬规定）。

## 5. 动效三条铁律

1. 每个动效必须写 `prefers-reduced-motion: reduce` 降级分支；用 CSS 动画驱动的临时 DOM（如回溯闪屏）要配 `setTimeout` 兜底清理，因为 `animation: none` 时 animationend 不会触发。
2. 浏览器 API 先判存在：jsdom 没有 `window.matchMedia`——漏判的下场是组件崩溃、ErrorBoundary 兜底、测试只报"文案找不到"（真实踩坑）。
3. 数值动画用 rAF + 缓动（参考 `src/components/panels.tsx` 的 useAnimatedNumber），时长 ≤500ms。

## 6. 触控与响应式底线

- 交互目标 ≥44px（含 select、搜索框的可点包装区）。
- fixed 悬浮元素放视口角落、默认半透明（参考 .term-fab 72%），不悬在内容中段。
- 断点体系：660px 主布局切换；弹窗高度用 `dvh`。
- 绝对定位的文字标签必须 `white-space: nowrap` + 末位右对齐锚定，防窄屏折行溢出（时间轴教训）。

## 7. 大文件先拆再加

超 500 行的组件（历史上 GameContainer 562 行）先按"状态管理/面板渲染/弹窗调度"拆分再加功能；拆出的组件如被契约测试 grep，同一提交内迁移断言。
