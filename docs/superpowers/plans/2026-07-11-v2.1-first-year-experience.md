# V2.1 First-Year Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a guided but non-forced first-year career loop that makes the current objective, opportunity chain, recommendation, and month-12 review understandable without changing core simulation formulas.

**Architecture:** Keep the game engine authoritative and derive all first-year UI from existing `GameState`. Reuse `autoChoiceSystem` for opportunity and crisis ordering, persist only two boolean flags in the existing `flags` record, and keep the new UI in focused components outside `GameContainer.tsx`.

**Tech Stack:** React 19, TypeScript 6, Vite 8, Vitest 4, jsdom, existing CSS token system, existing deterministic simulation scripts.

## Global Constraints

- Work only on `feat/v2.1-first-year-experience` until release integration.
- Do not add runtime dependencies, a state-management library, a backend, accounts, analytics, rankings, payments, actions, events, careers, or endings.
- Do not change salary, event, Offer, growth, ending, random-number, or crisis formulas.
- Do not force old saves or daily challenges into the V2.1 first-year flow.
- Recommendations are visible advice only and never execute actions automatically.
- Preserve lazy loading of `GameDialogs` and the popup event data chunk.
- User-visible copy is Chinese, causal, respectful, and free of implementation labels.
- Keep all interactive targets at least 44px and all component files at or below 500 lines.
- Use `npm test -- --maxWorkers=1` for the full Vitest suite.
- A release is blocked unless `releaseGate.passed=true` and deterministic replay rate is `1`.
- Production merge, deployment, and tag happen only after a separate backup and rollback check.

import { describe, expect, it } from 'vitest';
import { createInitialState, getAvailableActions } from '../core/gameEngine';
import {
  buildFirstYearReview,
  deriveFirstYearGuide,
  enableFirstYearExperience,
  markFirstYearReviewSeen,
  shouldShowFirstYearReview,

function newGuidedState() {

describe('first-year experience', () => {

    expect(guide?.recommendedActionId).toBe('project_practice');

    state.career.scheduledInterviews[0].status = 'completed';
    state.career.activeOffers.push({
      id: 'offer-1', companyType: 'private', jobLevel: 1,
      salaryMonthly: 16000, createdMonth: 5, expiresMonth: 8, status: 'active',
    });
    expect(deriveFirstYearGuide(state, getAvailableActions(state))?.recommendedActionId).toBe('C2002');

    state.career.activeOffers[0].status = 'accepted';
    state.career.employmentStatus = 'employed';
    expect(deriveFirstYearGuide(state, getAvailableActions(state))?.stageId).toBe('first_job');
  });

  it('lets a crisis override the normal career recommendation', () => {
    const state = newGuidedState();
    state.stats.mental = 20;
    const guide = deriveFirstYearGuide(state, getAvailableActions(state));
    expect(['therapy', 'sleep_repair', 'rest']).toContain(guide?.recommendedActionId);
  });

  it('does not activate for old saves or after review confirmation', () => {
    const oldSave = createInitialState('frontend', 'tier2', 1);
    expect(deriveFirstYearGuide(oldSave, getAvailableActions(oldSave))).toBeNull();

    const reviewed = markFirstYearReviewSeen(newGuidedState());
    expect(deriveFirstYearGuide(reviewed, getAvailableActions(reviewed))).toBeNull();

    const state = newGuidedState();
    state.month = 12;
    state.career.portfolioCount = 1;
    state.career.totalApplications = 2;
    state.career.totalInterviews = 1;
    expect(shouldShowFirstYearReview(state)).toBe(true);
    const review = buildFirstYearReview(state);
    expect(review.metrics.map(item => item.label)).toContain('投递/面试');
    expect(review.strength.length).toBeGreaterThan(0);
    expect(review.risk.length).toBeGreaterThan(0);
    expect(shouldShowFirstYearReview(markFirstYearReviewSeen(state))).toBe(false);
  });

```ts
const ELIGIBLE_FLAG = 'v21_first_year_experience';
const REVIEW_SEEN_FLAG = 'v21_first_year_review_seen';
```

Implementation rules:

```ts
export function enableFirstYearExperience(state: GameState): GameState {
  return { ...state, flags: { ...state.flags, [ELIGIBLE_FLAG]: true } };
}

export function markFirstYearReviewSeen(state: GameState): GameState {
  return { ...state, flags: { ...state.flags, [REVIEW_SEEN_FLAG]: true } };
}

export function shouldShowFirstYearReview(state: GameState): boolean {
  return state.flags[ELIGIBLE_FLAG] === true
    && state.flags[REVIEW_SEEN_FLAG] !== true
    && state.month >= 12
    && !state.gameOver
    && !state.pendingEventChoice;
}
```

`deriveFirstYearGuide` returns `null` when eligibility is absent or review is seen. Determine the stage from real state in this order: employed → `first_job`; portfolio present → `opportunity_chain`; otherwise → `entry_ticket`. Use at most three nodes per stage.

Call `chooseActionForStrategy(state, 'stable_cashflow')`, then accept that ID only if it exists and is available in the supplied action list. Otherwise choose the first available action. Use a fixed reason map for `project_practice`, `system_learning`, `job_hunt`, `J2003`, `C2002`, `regular_work`, `therapy`, `sleep_repair`, and `rest`; use the action's `benefitLabel` as the final fallback.
